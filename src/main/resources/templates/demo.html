🔄 Step 4

Status Workflow

Workout plans move through a role-based approval pipeline: DRAFT → SUBMITTED → APPROVED → PUBLISHED. Trainers can submit; only Admins can approve, reject, or publish. Select a plan below and advance it through the workflow.

📝
DRAFT
Created, being edited. Trainer or Admin can submit.
📤
SUBMITTED
Awaiting Admin review. Can be approved or rejected.
✅
APPROVED
Admin-approved. Ready to publish to all users.
🚀
PUBLISHED
Live. Visible to all users. Terminal state.

🤖 Step 5

AI Workout Assistant

FitBot is a fitness AI assistant powered by a deterministic demo engine — no external AI credentials required. Ask for workout plans, exercise advice, nutrition tips, or help with the workflow. In production, this would connect to a real AI API with credentials stored server-side.

💡 Try These Prompts

🌱 Beginner Weight Loss
"Create a beginner workout plan for weight loss"
💪 Muscle Groups
"What are the best exercises for chest and back?"
🥗 Nutrition Advice
"How much protein do I need per day?"
🔥 Advanced Powerlifting
"Design an advanced powerlifting programme"
🔄 Workflow Help
"How does the workflow status system work?"
⚡ Demo Mode Notice
FitBot responses are pre-programmed for demonstration purposes. In production, this would use a real LLM API (e.g., OpenAI GPT or Google Gemini) with credentials stored securely in server-side environment variables — never exposed to the frontend.
